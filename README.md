# 운명사주 정운타임즈 (정운타임즈 사주신문)

신문사 포털 형태의 사주 콘텐츠 사이트입니다. 마이데일리·뉴시스·일간스포츠 같은 **화이트 지면 + 마스트헤드 + 가로 카테고리 탭 + 속보 티커 + TOP 7 인기뉴스 + 오늘의 무료운세 + MBTI 특집 + 썸네일 리스트 + 기사 상세** 구조로 만들었습니다.

## 1면 구성 (2026-11-22 개편)

1. **TOP 7 인기뉴스** — 1면 최상단. 조회수 1위 기사는 큰 썸네일·30px 제목의 톱 카드, 2~7위는 큰 순위 숫자·썸네일·카테고리 태그와 함께 목록으로. 클릭하면 기사 상세로 이동.
2. **오늘의 무료운세** — 생년월일/띠를 넣으면 기운 지수·행운의 색·숫자·좋은 시간·한 줄 조언이 바로 나오는 큰 위젯.
3. **바탕화면 설치** — 헤더 버튼 + 무료운세 바로 아래 설치 배너(`data-install` → `beforeinstallprompt` 또는 홈 화면 추가 안내).
4. **사주프로그램 배너** — 「정운 사주분석 웹 프로그램 · 1년 이용권」 지면(`#/program`)으로 연결.
5. **MBTI 궁합 특집** — 커버스토리 + 궁합 기사 2건 + 무료 궁합 CTA.

> 사주프로그램은 실제 계산 프로그램 파일을 공개 배포하지 않습니다. 화면 미리보기(3장) + 결제 안내 모달로만 안내합니다(무료 배포 시 1년 이용권 판매와 겹치기 때문).

## 4P 뷰어

- **하얀 배경 요약 3장판(`4p/04.html`) 단일 버전**입니다(2026-11-23 통일). 버전 선택 탭은 없습니다.
- 예전 4종 링크(`#/4p/v1`~`#/4p/v3`)로 들어와도 같은 하얀 지면으로 정리됩니다.
- 휴대폰 프레임 안에서 스크롤되며, `새 창에서 크게 보기`·`인쇄용으로 열기`를 제공합니다.
- 각 4P의 마지막에 **찐 정밀 전문분석지 30P·60P·100P → https://adorable-gaufre-c07661.netlify.app/** 링크가 들어 있습니다.
- 100P 가격은 확정 요금(49,900원)으로 통일했습니다.

## 앱 설치(PWA)

- 안드로이드 크롬: `beforeinstallprompt`를 잡아 상단 **[바탕화면에 설치]** 버튼·무료운세 아래 설치 배너·모바일 설치 바에서 바로 설치 팝업을 띄웁니다.
- iOS 사파리 등 미지원 브라우저: `공유 → 홈 화면에 추가` 안내 모달을 띄웁니다.
- 이미 설치(standalone) 상태에서는 설치 버튼이 숨겨집니다.

## 매일 자동 리뉴얼 (2026-11-22 구축)

- `scripts/daily_update.py` — 오늘(KST) 간지를 만세력으로 계산해 기사 4편(오늘의 운세·화제의 인물·사주·재물·어젯밤 그 꿈)을 만들고, `data/articles.json` 에 **최근 60일 / 최대 120편**까지 누적한 뒤 `assets/js/articles-daily.js` 를 다시 써서 지면에 반영합니다. `--push` 를 주면 `hukstory/saju-project22` main 에 커밋·푸시합니다.
- **화제의 인물**은 `data/people.json` 풀에서 매일 다음 사람으로 넘어갑니다. 공개 프로필로 생년월일이 확인된 인물만 넣고, 기사 본문에 출처를 남깁니다. 그 사람의 사주팔자·오행·십성·2027 정미년 세운은 `scripts/saju_calc.py` 로 실제 계산합니다.
- 과거 호는 사이트의 `#/archive`(지난 기사 모아보기)에서 날짜·지면별로 볼 수 있습니다.
- `data/system_alerts.json` — GitHub Pages 한도(저장소 1GB·월 100GB)에 가까워지면 경고를 남깁니다. 지면에는 표시하지 않고 사장님에게만 보고합니다.
- 매일 05:30 실행은 `scheduled-actions/📰-정운타임즈-매일-새벽-자동-갱신-05-30/` 에 정의되어 있습니다. GitHub Actions 는 App 권한(`workflows`)이 없어 쓸 수 없습니다(푸시 거절 확인).
